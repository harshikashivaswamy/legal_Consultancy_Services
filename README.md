# Legal Consultancy Service

A premium, production-quality responsive web application called "Legal Consultancy Service", an AI-powered legal consultation marketplace inspired by modern SaaS platforms.

The application should have four major sections:

1. Public Landing Website

2. Client Portal

3. Lawyer Portal

4. Admin Portal

The AI Assistant should be available inside every portal instead of being a separate module.

--------------------------------

LANDING PAGE

--------------------------------

Design a modern premium homepage with a clean corporate UI using Navy Blue, White, Gold and Light Gray.

Hero Section:

- Large headline:

  "India's Smart Legal Consultation Platform"

- Subtitle explaining users can find verified lawyers, book appointments, upload legal documents, consult online, and receive AI legal guidance.

- Two CTA buttons:

  - Find a Lawyer

  - I'm a Lawyer

Display statistics:

- 100+ Verified Lawyers

- 1000+ Consultations

- 25+ Legal Categories

- 4.9 Average Rating

Include:

- Features section

- How it Works

- Legal Categories

- Testimonials

- FAQ

- Footer

--------------------------------

ROLE SELECTION

--------------------------------

When users click Get Started, do not immediately show login.

Instead display three beautiful cards:

Client Portal

- Find lawyers

- Book appointments

- Manage documents

- AI Assistant

Lawyer Portal

- Manage profile

- Availability calendar

- Appointment management

- Earnings

Admin Portal

- User management

- Lawyer verification

- Reports

- Analytics

Each card has its own Continue button.

--------------------------------

AUTHENTICATION

--------------------------------

Each role has separate Login and Register pages.

Use JWT authentication.
